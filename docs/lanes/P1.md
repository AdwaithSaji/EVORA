## Build (in order)
1. `evora/ingest/decode.py`: PyAV/OpenCV, sample `config.SAMPLE_FPS`, `ts = start_wallclock + frame_idx/fps`,
   JPEG frames to `config.FRAMES_DIR/<camera_id>/`, thumbnail per camera, insert into `frames`/`cameras` (`evora/core/db.py`).
2. `evora/index/embed.py`: SigLIP (`config.EMBED_MODEL`), fp16 batched on GPU, L2-normalized →
   `config.FRAMES_FAISS` (IndexFlatIP) + `FRAMES_IDS`. Expose `embed_images(list[PIL]) -> np.ndarray` and
   `embed_texts(list[str]) -> np.ndarray` — P2 imports these, so keep them stable.
   **Hand off frames index to P2 by hour 4** (upload `data/` to Drive).
3. `evora/detect/track.py`: YOLO-World (`config.DETECT_MODEL`, `set_classes(config.DETECT_VOCAB)`) +
   `model.track(persist=True, tracker="bytetrack.yaml")` per camera → `Track` rows + `detections`;
   best crop = largest × sharpest; SigLIP crop embedding → `TRACKS_FAISS` + `TRACKS_IDS`;
   dominant colors (HSV k-means → color names) into `Track.colors`.
4. Person–bag association: bag box overlapping a person box for ≥ N frames → person `attributes` += "carrying bag",
   plus "large bag" if bag area / person area > 0.25.
5. `evora/index/build.py` with `build(manifest_path)` / `load()`; switch `evora/index/__init__.py` off the mock.
   Must be resumable and print throughput. `evora/ingest/clips.py`: `cut_clip` via ffmpeg with config padding.
6. Unseen-footage runbook in README: new manifest → one command → app works.

Targets: 30 min × 4 cameras indexed in < 20 min on one RTX.
